## Ace LP 0.1.0

First port of LuckPerms to Pumpkin.

- Groups with inheritance and weights, a default group, and primary groups
- Contexts: world, dimension type, gamemode and server
- Temporary permissions and parents that expire on their own
- Prefixes, suffixes and meta
- Tracks with promote and demote
- `/lp` commands for users, groups and tracks; changes apply instantly
- LuckPerms-compatible JSON storage
- IPC API so other plugins can read groups, prefixes and meta
